# Getting Started

## Clone

git clone https://github.com/mo3z10/ECommerce.git

cd ECommerce

## Configure

Copy

.env.example

to

.env

and fill your values.

## Docker Image

docker pull mzy10/ecommerce-api:latest

## Run

docker compose up --build

API

http://localhost:8080

Swagger

http://localhost:8080/swagger

Hangfire

http://localhost:8080/hangfire
